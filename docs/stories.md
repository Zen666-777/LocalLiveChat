# プロットとロアブック

## 使い方

1. キャラクターを開き、会話画面の「メインストーリー」を押す。
2. 「新しいプロット」で、名前・あらすじ・舞台・開始状況・目標・最初の挨拶を入力して保存する。
3. 「ロアブック」から人物詳細・人物関係・場所・世界観などの項目を追加する。
4. ロアのチェックを切り替え、そのプロットで使う項目を選ぶ。
5. プロットを切り替えると、その物語の会話と長期記憶に戻る。

例：同じメルでも「日常のカフェ」と「学園の物語」は別の履歴・記憶になる。
キャラの基本的な容姿は共通にし、関係性や世界設定はプロットごとのロアで指定できる。

## キャラクター詳細とロア

- キャラ編集の「詳細プロフィール」は、そのキャラのすべてのプロットで使用する。
- ロアの「人物詳細」には、容姿・過去・口調・一人称・関係性などを自由に記入できる。
- ロアブックはキャラ内の資料集として共有し、使う項目のチェックをプロット別に保存する。
- 新規項目は、作成したときのプロットで使う設定になる。
- 同じロアを複数のプロットで選ぶと、本文の編集はそれぞれの次の会話に反映される。
- プロットごとに異なる設定を使う場合は、別のロア項目として作成して選択する。

キーワードが空欄のロアは、チェックしたプロットで常に使う。
カンマ・読点・改行でキーワードを指定すると、プロット設定または直近6件の会話に
どれかが含まれる場合だけ使う。英字の大文字・小文字は区別しない。

ローカルモデルの文脈上限は4096トークン。設定を大量に登録できても、一度にすべてを
読み込めるわけではない。必要な項目を選び、本文を短くするかキーワードを使う。
有効な設定だけで上限に近づいた場合はエラーを表示し、ロアを黙って切り捨てない。

## 記憶と保存

会話・自動要約・要約済み位置・手動で編集した記憶は、すべてプロットごとに保存する。
別のプロットの会話を要約へ混ぜない。ロアの設定は固定の資料、記憶はその物語で話した内容として扱う。
過去の記憶と新しい設定が食い違う場合は、現在の設定を優先するようモデルへ指示する。

- プロット編集：履歴と記憶を引き継ぐ。挨拶は新規作成時だけ追加する。
- プロット削除：そのプロットの履歴・記憶・ロア選択を削除する。資料の本文は残る。
- ロア削除：使っていたプロットの選択から外す。会話・記憶は残る。
- キャラ削除：そのキャラの全プロット・ロア・履歴・記憶を削除する。

ローカルモードでは、会話と要約を含めて端末内で処理する。
OpenRouterを選択した場合は、有効なキャラ詳細・プロット・ロアも会話の文脈として送信する。

## 既存データの更新

Roomのスキーマを1から2へ移行する。既存のキャラそれぞれに「メインストーリー」を作り、
元のメッセージID・内容・時刻・モデル・要約・更新位置を保持して引き継ぐ。
固定署名のAPKを上書き更新する。アプリの削除は不要。

テストでは保存済みのバージョン1スキーマから実際のDBを作成し、新しいDBへの移行と、
移行前の未回答の投稿を再試行できることを確認する。プロット間の履歴・記憶・要約・ロアの分離、
削除時の参照整合性、設定編集時の履歴保持も検証する。
